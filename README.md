# BOE – Extracción de sanciones (API oficial)

Proyecto en Python para analizar diariamente el BOE usando la API oficial
y detectar publicaciones relacionadas con sanciones administrativas.

## Funcionalidades
- Consulta del sumario diario del BOE (API oficial)
- Análisis de publicaciones
- Detección de sanciones mediante keywords
- Extracción de texto desde HTML / XML / PDF
- Exportación a CSV y JSON
- Base de datos SQLite
- Interfaz con Streamlit

## Requisitos

- Python 3.9+
- pip

## Instalación

python -m venv boe
source boe/bin/activate
pip install -r requirements.txt
